# Combobox

Combobox provides an autocomplete filterable dropdown list pairing a trigger with a searchable popup.

## Installation

```bash
npx shadcn@latest add @tuiparts/combobox
```

## Structure

- `Combobox`: Root container managing selected value and open state.
- `ComboboxTrigger`: Select-like trigger button with label and chevron.
- `ComboboxContent`: Dropdown popup container.
- `ComboboxInput`: Filter search text field.
- `ComboboxList`: List wrapper for options.
- `ComboboxEmpty`: Fallback displayed when no options match filter.
- `ComboboxItem`: Selectable option with checkmark indicator.
