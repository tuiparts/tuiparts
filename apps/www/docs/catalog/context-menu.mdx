# ContextMenu

ContextMenu provides target area context menus triggered by secondary pointer actions or shortcuts.

## Installation

```bash
npx shadcn@latest add @tuiparts/context-menu
```

## Structure

- `ContextMenu`: Root container managing open state.
- `ContextMenuTrigger`: Target area defining the context zone.
- `ContextMenuContent`: The popup menu box.
- `ContextMenuItem`: Standard selectable action item.
- `ContextMenuCheckboxItem`: Selectable item with checkbox state.
- `ContextMenuRadioItem`: Selectable item with radio button state.
- `ContextMenuLabel`: Heading typography.
- `ContextMenuSeparator`: Section divider line.
- `ContextMenuShortcut`: Right-aligned shortcut key hint.
- `ContextMenuGroup`: Semantic items group container.
