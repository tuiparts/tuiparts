# Drawer

Drawer is a bottom-docked overlay with grab handle and framed action regions.

## Installation

```bash
npx shadcn@latest add @tuiparts/drawer
```

## Structure

- `Drawer`: Root context provider managing open state.
- `DrawerTrigger`: Opens the drawer.
- `DrawerContent`: The overlay backdrop and bottom docked content box.
- `DrawerHeader`, `DrawerFooter`: Framing layout containers.
- `DrawerTitle`, `DrawerDescription`: Semantic typography labels.
- `DrawerClose`: Dismissal trigger.
