# DropdownMenu

DropdownMenu provides actionable popup menus triggered by button elements.

## Installation

```bash
npx shadcn@latest add @tuiparts/dropdown-menu
```

## Structure

- `DropdownMenu`: Root container managing open state.
- `DropdownMenuTrigger`: Activator button element.
- `DropdownMenuContent`: The framed popup container.
- `DropdownMenuItem`: Standard selectable action item.
- `DropdownMenuCheckboxItem`: Selectable item with checkbox state.
- `DropdownMenuRadioItem`: Selectable item with radio button state.
- `DropdownMenuLabel`: Heading typography.
- `DropdownMenuSeparator`: Section divider line.
- `DropdownMenuShortcut`: Right-aligned shortcut key hint.
- `DropdownMenuGroup`: Semantic items group container.
