# HoverCard

HoverCard displays rich preview content attached to a trigger with hover delays.

## Installation

```bash
npx shadcn@latest add @tuiparts/hover-card
```

## Structure

- `HoverCard`: Root context provider managing open state and delays.
- `HoverCardTrigger`: Focus or pointer hover target.
- `HoverCardContent`: The preview popover box.
