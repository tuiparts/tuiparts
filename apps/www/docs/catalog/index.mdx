The Catalog contains editable Recipes for Core, React, and Solid. Interactive
Recipes build on either packaged Primitives or behavior already owned by
OpenTUI; presentation-only Recipes use OpenTUI directly. Native behavior does
not receive a pass-through Foundation package merely to make the inventory
symmetrical.

Choose a Recipe below. Its page provides the exact Core, React, and Solid
install commands alongside usage and customization guidance.

## Choose a Recipe

| Recipe | Use it for | Packaged behavior |
| --- | --- | --- |
| [Button](/catalog/button) | An action without retained on/off state | Activation, pressed state, focus, disabled behavior |
| [Input](/catalog/input) | Single-line text entry | OpenTUI-native editing and events |
| [Number Field](/catalog/number-field) | Numeric entry, bounded stepping, and pointer scrubbing | Draft parsing, value ownership, commits, and terminal-cell dragging |
| [Textarea](/catalog/textarea) | Multiline text entry | OpenTUI-native EditBuffer and events |
| [Checkbox](/catalog/checkbox) | An independent checked choice | Checked state and activation |
| [Checkbox Group](/catalog/checkbox-group) | Related choices checked independently with one keyboard stop | Array ownership and roving focus |
| [Switch](/catalog/switch) | A setting that takes effect immediately | Checked state and activation |
| [Toggle](/catalog/toggle) | An action whose pressed state remains visible | Pressed state and activation |
| [Toggle Group](/catalog/toggle-group) | Related toggles sharing one keyboard stop | Selection and roving focus |
| [Collapsible](/catalog/collapsible) | Reveal optional content beneath one Trigger | Open state, activation, and Panel lifecycle |
| [Accordion](/catalog/accordion) | Organize related disclosure Items | Single or multiple expansion, activation, and Panel lifecycle |
| [Tabs](/catalog/tabs) | Switch between associated content panels | Selection, association, and roving focus |
| [Radio Group](/catalog/radio-group) | One mutually exclusive selection from a set | Selection and roving focus |
| [Dialog](/catalog/dialog) | A short modal task or decision | Layers, dismissal, and focus containment |
| [Badge](/catalog/badge) | Non-interactive status text | None; Recipe only |

## Recipes are source you own

Use an installed Recipe directly, reshape it into your house style, or publish
the adapted source through your own Registry. React and Solid Recipes expose
JSX functions; Core Recipes expose imperative factory functions. Each file
owns its convenience API and composition.

Application-wide colors, glyphs, borders, and density resolve from the
[Theme Recipe](/theming). Per-instance labels, marks, variants, and layout
remain ordinary source in the installed Recipe.

When a Recipe's composition or public API does not fit, use the underlying
[Primitive](/primitives) to assemble the behavior yourself. To understand the
ownership boundary, read [Architecture](/architecture). To compare upstream
source after installation, read [Registry](/registry#review-updates).
