# ASCIIBanner Recipe

Consumer-owned ASCIIBanner recipe wrapping OpenTUI's native `ASCIIFontRenderable` with theme colors and optional subtitles.

## Features

- **Figlet ASCII Fonts**: Supports `"block"`, `"tiny"`, `"shade"`, `"slick"`, `"huge"`, `"grid"`, and `"pallet"`.
- **Theme-Reactive Colors**: Font color defaults to `tokens.colors.primary` with instant updates on theme changes.
- **Subtitle Layout**: Optional secondary label rendered underneath the banner with muted styling.
