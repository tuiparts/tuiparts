# DiffViewer Recipe

Consumer-owned DiffViewer recipe wrapping OpenTUI's native `DiffRenderable` with theme borders, titles, and unified or split views.

## Features

- **Themed Framing**: OpenTUI native border styling and surface backgrounds.
- **Header Bar**: Optional file title and view mode badge (`UNIFIED` / `SPLIT`).
- **Unified & Split Views**: Side-by-side or inline patch rendering.
- **Syntax Highlighting**: Automatic tree-sitter syntax highlighting via `filetype`.
