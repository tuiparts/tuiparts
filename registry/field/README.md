# Field Recipe

Consumer-owned Field recipe for structuring form inputs with labels, helper descriptions, error messages, and fieldset groupings. Inspired by shadcn-ui.

## Features

- **Field**: Vertical or horizontal container for form elements.
- **FieldLabel**: High-contrast label with optional required asterisk indicator.
- **FieldDescription**: Muted context / help text.
- **FieldError**: Destructive-colored error text supporting single messages or error arrays.
- **FieldSet & FieldGroup**: Structured grouping containers with consistent gap spacing.
- **FieldLegend**: Section headers for fieldsets.
- **FieldSeparator**: Section divider line with optional label.
- **FieldContent**: Flexible container for controls in horizontal layout configurations.
