# MarkdownViewer Recipe

Consumer-owned MarkdownViewer recipe wrapping OpenTUI's native `MarkdownRenderable` with theme borders, titles, and structured syntax highlighting.

## Features

- **Themed Framing**: OpenTUI native border styling and surface backgrounds.
- **Header Bar**: Optional file title and `MD` badge.
- **Rich Markdown Formatting**: Headings, lists, code blocks, and markdown tables.
- **Syntax Highlighting**: Code blocks formatted with tree-sitter.
