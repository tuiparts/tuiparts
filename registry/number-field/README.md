# NumberField Recipe

Editable NumberField presentation for Core, React, and Solid. The Recipe uses
the packaged NumberField Primitive for numeric ownership, draft editing,
keyboard and press stepping, bounds, commits, and terminal-cell scrubbing.
Installed source owns the label, glyphs, layout, spacing, and theme colors.

Install the item for your runtime:

```bash
pnpm dlx shadcn@4.13.0 add @tuiparts/react/number-field
pnpm dlx shadcn@4.13.0 add @tuiparts/solid/number-field
pnpm dlx shadcn@4.13.0 add @tuiparts/core/number-field
```

The NumberField item depends on the matching Theme Recipe, so the CLI installs
that editable source with it.
