# Pagination Recipe

Consumer-owned Pagination recipe for terminal navigation. Inspired by shadcn-ui.

## Features

- **Pagination**: Centered navigation bar container.
- **PaginationContent**: Row container with consistent spacing.
- **PaginationItem**: Individual wrapper for items.
- **PaginationLink**: Page button showing page number with active primary highlight.
- **PaginationPrevious & PaginationNext**: Navigation links with arrow chevrons (`‹`, `›`).
- **PaginationEllipsis**: Compact indicator for skipped page spans.
