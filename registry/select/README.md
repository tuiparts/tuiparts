# Select Recipe

An accessible dropdown select recipe for OpenTUI applications.

## Features

- Trigger box showing current selection or placeholder with toggle indicator.
- Floating dropdown list of options with checkmark indicators.
- Keyboard navigation (Up/Down arrows to rove, Enter/Space to select, Escape to close).
- Pointer click / tap selection support.
- Full integration with OpenTUI theme tokens.

## Files

- `core.ts`: Imperative OpenTUI Renderable (`SelectComponentRenderable`, `createSelect`).
- `react.tsx`: Declarative compound components (`Select`, `SelectTrigger`, `SelectValue`, `SelectContent`, `SelectItem`, `SelectGroup`, `SelectLabel`, `SelectSeparator`).
- `solid.tsx`: Reactive compound components (`Select`, `SelectTrigger`, `SelectValue`, `SelectContent`, `SelectItem`, `SelectGroup`, `SelectLabel`, `SelectSeparator`).
