# Slider Recipe

Editable Slider presentation for Core, React, and Solid. The Recipe uses the
packaged Slider Primitive for bounded value ownership, decimal-safe keyboard
steps, focus, terminal-cell track presses, captured dragging, and commit
timing. Installed source owns the label, value formatting, dimensions, glyphs,
layout, and theme colors.

Install the item for your runtime:

```bash
pnpm dlx shadcn@4.13.0 add @tuiparts/react/slider
pnpm dlx shadcn@4.13.0 add @tuiparts/solid/slider
pnpm dlx shadcn@4.13.0 add @tuiparts/core/slider
```

The Slider item depends on the matching Theme Recipe, so the CLI installs that
editable source with it.
