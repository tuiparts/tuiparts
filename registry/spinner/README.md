# Spinner Recipe

The Spinner recipe renders an animated activity indicator with customizable glyph presets, speed, intent colors, and optional label text.

## Features

- Built upon `@tuiparts/core/spinner`, `@tuiparts/react/spinner`, and `@tuiparts/solid/spinner`
- Frame glyph presets: `braille` (default), `dots`, `line` (classic ASCII), `arc`, `pulse`, `arrow`
- Semantic intents: `primary`, `neutral`, `muted`, `success`, `warning`, `danger`
- Themed reactive styling synchronizing with `useTheme`
- Optional trailing label and custom children
