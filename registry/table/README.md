# Table Recipe

A responsive, composable terminal Table recipe providing compound layout parts for structured tabular data.

## Features

- Flexible row and cell grid using Yoga flexbox layout
- Compound parts: `Table`, `TableHeader`, `TableBody`, `TableFooter`, `TableRow`, `TableHead`, `TableCell`, `TableCaption`
- Theme-driven borders, muted header foregrounds, and customizable row divider lines
- Supports custom cell contents such as badges, icons, inputs, and buttons
