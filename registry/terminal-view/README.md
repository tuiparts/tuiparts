# TerminalView Recipe

Consumer-owned TerminalView recipe providing a styled terminal window emulator frame with window controls, header metadata, prompt, and output lines.

## Features

- **Window Chrome**: Header bar with traffic lights (`● ● ●`) and title label.
- **Themed Borders**: Automatic border and surface coloring synced with the theme store.
- **Buffer Display**: Supports string line buffers, prompt rows, and custom child widgets.
