# Tooltip Recipe

A non-disruptive contextual tooltip / hover hint recipe for OpenTUI.

## Features

- Styled popover frame with theme tokens.
- Mouse over / mouse out triggering.
- Composable declarative trigger and content structure.

## Files

- `core.ts`: Imperative OpenTUI Renderable (`TooltipRenderable`, `createTooltip`).
- `react.tsx`: Declarative React components (`TooltipProvider`, `Tooltip`, `TooltipTrigger`, `TooltipContent`).
- `solid.tsx`: Reactive Solid components (`TooltipProvider`, `Tooltip`, `TooltipTrigger`, `TooltipContent`).
